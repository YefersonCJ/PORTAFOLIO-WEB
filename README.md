## Ejecutar localmente

Puedes abrir `index.html` directamente en el navegador.

También puedes usar un servidor local:

```bash
python -m http.server 8000
```

Después visita:

```text
http://localhost:8000
```

## Desplegar en Vercel

1. Crea un repositorio en GitHub.
2. Sube todos los archivos de esta carpeta.
3. En Vercel selecciona **Add New → Project**.
4. Importa el repositorio.
5. Para este proyecto estático no necesitas un build command.
6. Deja el Root Directory en la raíz del repositorio.
7. Haz clic en **Deploy**.

## Antes de publicar

En `index.html`, reemplaza:

```text
https://TU-DOMINIO.vercel.app/
```

por el dominio real de tu proyecto para las etiquetas Open Graph.

Después de conocer tu dominio definitivo también puedes agregar una etiqueta canonical absoluta.
